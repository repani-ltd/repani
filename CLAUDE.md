# repani (module repani.com)

One Go module, several projects: `prim/`, `pica/`, `fact/`. Each has
its own CLAUDE.md with the project rules; this file holds what is
common.

- Import paths are `repani.com/<dir>/...`; the module is the repo
  root, so never add a nested go.mod (the only exception is
  `pica/tmp`, a scratch module that is deliberately outside).
- CLIs live in `<project>/cmd/<tool>`: `pica/cmd/pica`,
  `fact/cmd/fact`.
- Every Go package carries a generated `pkg.fact` (see
  `fact/CLAUDE.md` and `fact/docs/using-pkg-fact.md`). Hooks:
  `.claude/settings.json` runs `fact hook` after edits; install the
  git hooks once per clone with `cp fact/docs/pre-commit
  fact/docs/post-commit .git/hooks/`.
- `fact/facts/` holds third-party projections (FACT SPEC 11.5); they
  are regenerated by import path, not by `fact project -w`.
- Documentation in pica: `pica spec`, `pica check FILE.t` (see
  `~/repos/CLAUDE.md`).
- Build and test the whole module: `go build ./... && go test ./...`.
