# Hyphenation patterns

Knuth-Liang hyphenation pattern files, embedded into the library at
compile time.

- `en.txt` -- English patterns, derived from Frank Liang's hyphen.tex
  patterns for TeX (Donald Knuth's TeX distribution).
- `el.txt` -- Greek patterns, derived from the TeX hyph-utf8 Greek
  pattern set.

The TeX hyphenation patterns are distributed under their own
licences (generally free for any use with attribution; see the
hyph-utf8 project, https://hyphenation.org/, for the per-language
provenance and licence texts). If you redistribute this repository,
keep this notice.
