# raster.js

A decoder and DOM painter for raster pages, the JavaScript
implementation of RASTER.t beside the Go one. ES module, no
dependencies.

- `decode(bytes, {cols, rows, panels})` returns panels of rows of
  cells `{glyph, fg, bg}`; `decodeRow(bytes)` one row.
- `text(cells)`, `html(cells)`, `links(cells)` render one row the way
  the Go renderers do; `TABLE` is the cell table.
- `paint(pre, panel, onTap)` writes a panel into a `<pre>` and reports
  tapped link targets.

`fixture.json` is generated by the Go tests (`go test -run
TestFixture -update`) and holds the Go implementation's answers;
`node --test raster_test.js` checks this one against them, and
`go test` runs it when node is installed.
