# lz4s.js

lz4s in JavaScript, beside the Go one. ES module, no dependencies.

- `decompress(comp, dsize)` decodes a stream into exactly `dsize`
  bytes, or returns null.
- `compress(src)` is `lz4s.Compress`: the same parse, so the fixture
  can compare their streams.

`fixture.json` is generated by the Go tests (`go test -run
TestFixture -update`) and holds the Go implementation's streams;
`node --test lz4s_test.js` checks this decoder, and this compressor,
against them, and `go test` runs it when node is installed.
