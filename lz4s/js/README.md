# lz4s.js

The lz4s decoder in JavaScript, beside the Go one. ES module, no
dependencies.

- `decompress(comp, dsize)` decodes a stream into exactly `dsize`
  bytes, or returns null.
- `undelta(base, comp, dsize)` decodes a stream made against `base`
  (`lz4s.Delta` in Go); the base must be the same bytes.

`fixture.json` is generated by the Go tests (`go test -run
TestFixture -update`) and holds the Go implementation's streams;
`node --test lz4s_test.js` checks this decoder against them, and
`go test` runs it when node is installed.
