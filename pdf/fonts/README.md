Fira Mono (Regular, Bold) and Fira Sans (Regular, Bold), by the
Mozilla Foundation with Carrois Corporate GbR and Edenspiekermann
AG. Licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). The OFL permits bundling, embedding,
and redistribution; if you redistribute this repository publicly,
include the full OFL license text alongside these files.

Coverage relevant to this package: Latin, Greek, and Cyrillic. Fira
Mono advances are a uniform 600/1000 em (true monospace across
scripts); Fira Sans is the proportional companion face used by
".font sans" documents.
